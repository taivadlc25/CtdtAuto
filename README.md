# CtdtAuto - Captain Tsubasa Dream Team Automation Tool

Ứng dụng tự động hỗ trợ chơi game Captain Tsubasa Dream Team (CTDT) trên giả lập MEmu.

## Tính năng chính
- Tự động thực hiện các chế độ: Cup Championship, Training SSR, League, Raid, Event, Story, World Challenge.
- Tự động nhận quà và Daily Ads.
- Hỗ trợ đổi kích thước cửa sổ giả lập, neo cửa sổ, docking thông minh.
- **Tự động kiểm tra và nâng cấp trực tuyến khi có phiên bản mới qua GitHub Releases.**

## Tải về
Tải phiên bản mới nhất tại: [Releases](https://github.com/taivadlc25/CtdtAuto/releases)
File thực thi chính: `CtdtAuto.exe`
